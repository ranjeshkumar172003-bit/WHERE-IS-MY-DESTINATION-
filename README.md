# WHERE IS MY DESTINATION

Android-ready starter application with a colorful English interface, destination entry, Clear button, transport-mode row, and Google Maps navigation intent.

## GitHub Actions
Push the project contents to GitHub. The included `.github/workflows/main.yml` builds a debug APK and uploads it as an Actions artifact.

## Important
The supplied branding artwork is included unchanged as `app/src/main/res/drawable/brand_promo.png` and `brand_promo_alt.png`.
